#  Credit Card Default Prediction

##  Project Overview

Credit Card Default Prediction is a Machine Learning project designed to predict whether a credit card customer is likely to default on future payments based on historical customer information and payment behavior.

The project uses data analysis and classification techniques to identify patterns associated with payment defaults and evaluate the performance of predictive models.

##  Technologies Used

- **Programming Language:** Python
- **Data Analysis:** Pandas, NumPy
- **Data Visualization:** Matplotlib, Seaborn
- **Machine Learning:** Scikit-learn
- **Development Environment:** Jupyter Notebook
- **Dataset:** UCI Credit Card Default Dataset

##  Dataset Information

The project uses the UCI Credit Card Default dataset, which contains information about credit card customers, including:

- Customer demographics
- Credit limit
- Repayment status
- Previous payment amounts
- Bill statement amounts
- Payment history

The target variable represents whether a customer defaulted on their payment in the following month.

##  Model Evaluation

The following metrics can be used to evaluate the classification models:

- **Accuracy:** Overall proportion of correct predictions.
- **Precision:** Proportion of predicted defaults that are actual defaults.
- **Recall:** Proportion of actual defaults correctly identified.
- **F1-Score:** Balance between precision and recall.
- **Confusion Matrix:** Breakdown of correct and incorrect predictions.
- **ROC-AUC:** Ability to distinguish between the two classes.

##  Real-World Applications

- Credit risk assessment
- Financial risk management
- Customer payment behavior analysis
- Early identification of potential payment defaults
- Supporting data-driven lending decisions
